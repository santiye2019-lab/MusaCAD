# First-party immutable viewport plan (2026-11-02)

- **Scope:** Only `core/firstparty/dwg1032/` in the existing MusaCAD branch. The new `musa_dwg1032_viewport_plan_init` validates a caller-supplied, already-decoded sorted layer/viewport table once. `musa_dwg1032_viewport_plan_page` resolves bounded entity pages without rescanning all layer/override metadata for every page. This improves the algorithmic cost for small pages of large drawings; no real-file timing measurement has been made.
- **Source provenance:** This C11 implementation and synthetic test were authored independently for MusaCAD using standard-language bounds checks and binary search, with first-party layer/viewport data types. No GPL, AGPL, LGPL, LibreDWG, legacy native core, or unknown-origin implementation was copied, adapted, or linked into this new module. The standalone CMake target continues to link only first-party code.
- **Immutability requirement:** After successful plan initialization, the caller MUST keep both tables and their backing storage unchanged and alive until the last page query. A viewport change requires reinitialization. A plan is **not** a self-authenticating snapshot of mutable memory; violating this lifetime contract invalidates its guarantees.
- **Atomic publication:** Plan initialization validates strict Boolean flags, unique sorted nonzero handles, and override membership before publishing the plan. A page validates all its handles/flags before publishing any output. The full entity arrays, plan and metadata must not overlap the output, including future source pages. Invalid ranges and aliases fail without changing output.
- **Synthetic tests:** 20,000 entities, 128 layers, 16 overrides, page sizes 1/7/257/1024/20000, viewport changes with plan reinitialization, malformed metadata, late invalid entities, oversized ranges and source/output aliasing. CI runs the test via the independent C11 CMake target.
- **Limits:** These routines do NOT discover/decompress/authenticate AC1032 pages, decode TEXT/MTEXT/INSERT records, infer owner chains, or grant final render permission. Android integration and historical GPL-marked application linkage remain separate, unresolved gates. Do not infer full 2D DWG fidelity or CAD parity from these tests.
