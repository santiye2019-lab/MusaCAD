# Independent decoded-layer pagination (2026-10-30)

- Scope: `musa_scene2d_layers_from_cad_page` converts a bounded row of **already decoded** layer attributes to independent scene-layer records. A requested page uses O(page size) work and no heap allocation; it does not scan earlier records. A zero-capacity query returns the total count.
- Fidelity: each selected layer retains its original handle and uses the existing, independently written signed-ACI off/on, frozen, viewport-frozen, true-color and caller-supplied 256-entry palette conversion. ACI colors without a verified palette are not invented.
- Safety: count multiplication, invalid palette shapes, RGB bounds, source/output/metadata aliases, and late malformed records are checked before any output is published. A failure preserves the destination page and both count outputs.
- Test: `independent_scene2d_layer_paged_20k` crosschecks every page against the existing full-batch converter for 20,000 synthetic layers; includes late corruption, empty pages, aliasing, invalid palette and capacity bounds. A passing synthetic test does **not** prove any real AC1032 DWG layer was decoded.
- Origin: authored specifically for this repository using ordinary C11 arithmetic and the already present first-party scene layer adapter. No LibreDWG, GPL/AGPL/LGPL, historical CAD implementation, SDK code, or code of uncertain origin was copied, adapted, imported or linked. New code is MIT SPDX.
- Boundary: this module does not find or decompress AC1032 sections, parse the LAYER table, decode TEXT/MTEXT, infer BLOCK/INSERT ownership, open a real DWG or enable Android rendering. Those remain explicit acceptance gates. Production JNI, `MusaCAD2/`, `main` and existing 3D sources are unchanged. CI must be checked for the **exact** head commit before reporting a passing gate.
