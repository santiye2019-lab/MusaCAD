# Independent planar INSERT-array paging — 2026-10-30

- **Scope:** `core/firstparty/scene2d/` in the existing MusaCAD repository. The new `musa_scene2d_array_fill_page` API accepts predecoded planar array dimensions and transforms, starts at a caller-selected row-major index, and emits at most the requested page into caller-owned memory. It reports total instance count, validates the entire requested page before publishing output, and rejects arithmetic overflow, invalid placement, nonfinite coefficients and overlapping output buffers.
- **Motivation:** Large rectangular block arrays should not require materializing or visiting all earlier instances to display one visible page. This API's work is proportional to the page size rather than the preceding instance count; no measured runtime speedup or production rendering integration is claimed.
- **Verification:** A dedicated CTest compares every generated affine against the existing full-array evaluator over 20,000 synthetic instances, tests empty and out-of-range pages, zero-capacity queries, buffer aliasing, count overflow and atomic failure for a later nonfinite transform. Confirm CI status on the exact commit; test registration is not itself a successful test.
- **Provenance:** Independently authored MIT C11 implementation from elementary affine arithmetic and bounded indexing. No GPL, AGPL, LGPL, LibreDWG, unknown-origin CAD code, external SDK or historical MusaCAD decoder was copied, adapted, linked or consulted as an implementation template.
- **Limitations:** This does **not** decode AC1032 compressed pages, DWG object records, MINSERT or extrusion/OCS, nor establish original DWG colors, layer visibility, text rendering or Android JNI compatibility. Actual DWG fixtures and end-to-end validation remain required. Existing 3D sources, `MusaCAD2/` and `main` were not modified; PR #705 must remain unmerged.
